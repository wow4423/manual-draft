01

여권 QR 생성하기

여권 QR 생성하기

따라 할 순서

  1. 묶음명 / 지점 / 수량 입력
  2. 묶음과 코드 목록 확인
  3. 납품용 코드목록 다운로드
✓ 완료 확인

묶음의 지점, 수량과 미등록 재고를 확인합니다.

! 주의사항

인쇄업체에는 ‘납품용 코드목록’을 전달합니다. ‘관리용 내보내기’에는 회원 식별자가 포함되므로 전달하지 않습니다. 테스트 주소로 인쇄 발주하지 마세요.

조작 순서
메뉴 경로

CRM›여권QR생성›발행/배치관리

  1. 01발행 묶음 만들기에서 묶음명, 지점, 수량을 입력합니다.
  2. 02발행한 묶음을 열고 코드 목록을 확인합니다.
  3. 03납품용 코드목록을 다운로드합니다.
Q발행 총량과 배포할 수량이 다른가요?

이미 등록했거나 폐기한 QR도 발행 총량에 포함됩니다. 배포할 수량은 ‘미등록 재고’에서 확인합니다.

02

여권 등록하기

여권 등록하기

등록 방법

일반 카메라QR 스캔 → 링크 열기
또는
마이페이지주렁여권 → 여권 등록
✓ 완료 확인

마이페이지에서 등록한 가족의 프로필을 열고 ‘등록 여권 확인하기’로 여권을 확인합니다.

! 주의사항

여권을 사용할 가족을 확인합니다. 일반 카메라는 QR 인식 후 가족을 선택하고, 마이페이지는 등록할 가족의 프로필에서 시작합니다.

Q등록할 가족이 목록에 없으면 어떻게 하나요?

일반 카메라로 등록할 때 가족 선택 화면에서 ‘가족 추가하기’를 누른 뒤 등록할 가족을 선택합니다.

Q마이페이지에서는 누구의 여권으로 등록되나요?

등록을 시작한 프로필의 여권으로 등록됩니다. 사용할 가족의 프로필에서 ‘등록 여권 확인하기’를 누른 뒤 +를 누르세요. QR을 스캔하기 전에 카메라 화면에 표시된 이름을 확인합니다. 일반 카메라로 시작한 경우에는 QR을 읽은 뒤 가족을 선택합니다.

Q유효하지 않은 여권이라고 화면에 뜹니다.

새로운 여권이 등록되지 않는다면 해당 QR이 문제일 가능성이 있습니다. 부착된 QR을 변경해주세요.

03

쿠폰/촬영권 준비하기

쿠폰 생성하기

따라 할 순서

  1. 상품과 적용 지점 선택
  2. 혜택과 사용 조건 입력 후 저장
  3. 승인 권한이 있는 담당자가 활성 처리
✓ 완료 확인

상품, 지점, 혜택이 의도한 내용과 같고, 승인 및 활성 상태입니다.

! 주의사항

쿠폰 생성과 고객에게 발급하는 것은 별도입니다. 일반 쿠폰은 적용 지점을 비우면 전 매장에 적용됩니다. 사진 촬영권 쿠폰은 지점 한 곳을 선택합니다.

조작 순서
메뉴 경로

CRM›쿠폰›새 쿠폰

  1. 01상품 검색에서 정확한 상품명, 상품 ID를 확인합니다.
  2. 02상품, 적용 지점, 표시 이름, 종류와 할인 조건을 입력합니다.
  3. 03사용시간, 유효기간, 한도, 할인 중복 조건을 확인하고 저장합니다.
  4. 04승인 권한이 있는 담당자가 목록의 ‘활성’을 누른 뒤, 상태 ‘활성’과 승인 ‘승인됨’을 확인합니다.
Q상품을 여러 개 선택하면 모두 할인되나요?

일반 할인과 무료 쿠폰은 선택한 상품 중 장바구니에 담긴 1개에만 적용됩니다. 예를 들어 HOT과 ICE 아메리카노를 선택해도 할인 대상은 1잔입니다.

QN+M의 구매 수량과 증정 상품은 어떻게 정하나요?

선택한 상품들의 수량을 합산해 N개 충족 여부를 판단합니다. 증정 상품을 비워두면 구매 조건에 사용한 같은 상품이 M개 무료 처리됩니다. 다른 상품을 주려면 증정 상품을 따로 선택합니다.

Q사용 종료 시각과 유효기간은 어떻게 적용되나요?

종료 시각을 18:00으로 설정하면 정확히 18:00부터 사용할 수 없습니다. 유효기간은 쿠폰을 만든 날이 아니라 고객에게 발급한 날을 기준으로 계산합니다.

Q발급 후 조건이 잘못된 것을 알았다면?

발급 이력이 생긴 쿠폰은 이름 외 조건을 수정할 수 없습니다. 잘못된 쿠폰은 비활성화하고 올바른 조건으로 새로 만듭니다.

쿠폰 발급하기

따라 할 순서

  1. 쿠폰 선택 → 즉석발행
  2. 지급할 회원 선택
  3. 사유 입력 → 발행
✓ 완료 확인

‘발행 완료’ 메시지와 발행 번호를 확인합니다.

! 주의사항

같은 전화번호의 부모, 자녀를 구분합니다. 이 화면의 발급으로 알림톡이 자동 발송되지는 않습니다.

조작 순서
메뉴 경로

CRM›쿠폰›해당 쿠폰의 즉석발행

  1. 01쿠폰의 상태 ‘활성’과 승인 ‘승인됨’을 확인하고 ‘즉석발행’을 누릅니다.
  2. 02전화번호, 닉네임, 회원번호로 검색해 지급할 회원을 선택합니다.
  3. 03발행 사유를 입력하고 확인합니다.
Q여권 혜택 쿠폰을 자동으로 발급하려면?

아래 ‘여권 패키지 설정하기’에서 쿠폰과 수량을 구성합니다. 패키지의 적용 지점, 운영 기간, 활성 상태를 확인합니다.

사진 촬영권 쿠폰 등록/사용하기

따라 할 순서

  1. 지점 선택 → 번호 파일 열기
  2. 미리보기 확인 → 번호 등록
  3. 촬영권 쿠폰 생성 → 담당자 승인
✓ 완료 확인

선택한 지점에 사용 가능한 번호가 있고, 발급된 촬영권이 번호 형식으로 표시됩니다.

! 주의사항

사용 가능한 번호가 없으면 촬영권 쿠폰을 발급할 수 없습니다. ‘발급됨’ 수량은 촬영을 마친 고객 수가 아닙니다.

조작 순서
메뉴 경로

CRM›촬영권 번호 / 쿠폰›새 쿠폰

  1. 01지점 선택 후 업체 파일(TXT, CSV, XLSX)을 열어 미리보기를 확인합니다.
  2. 02미리보기의 지점명, 파일명, ‘채택’, ‘제외’를 확인한 뒤 ‘적재’를 눌러 번호를 등록합니다.
  3. 03신규 등록된 번호 수와 사용 가능한 번호 수를 확인합니다.
  4. 04쿠폰에서 사진관 상품, 지점 한 곳, ‘사진 촬영권 (번호 입력 방식)’을 선택하고, 저장 후 승인 권한이 있는 담당자가 ‘활성’ 처리합니다.
Q파일의 번호 중 일부만 등록됐어요.

파일 안의 중복 번호, 선택한 지점에 이미 등록된 번호, 번호로 인식되지 않은 값은 제외될 수 있습니다. 미리보기의 ‘채택’과 ‘제외’를 확인하세요. XLSX는 첫 번째 시트만 읽습니다.

Q다른 지점에 같은 번호가 있어도 되나요?

촬영권 번호는 지점별로 관리합니다. 같은 번호라도 지점이 다르면 각각 등록될 수 있으므로 번호와 소속 지점을 함께 확인합니다.

여권 패키지 설정하기

따라 할 순서

  1. 비활성 패키지 만들기
  2. 쿠폰과 발급 수량 추가
  3. 검수 → 자동 발급 활성화
✓ 완료 확인

패키지의 지점, 기간, 쿠폰 구성이 맞고 자동 발급이 활성 상태입니다.

! 주의사항

패키지 운영 기간은 자동 발급하는 기간입니다. 이미 발급된 쿠폰의 유효기간과는 다릅니다.

조작 순서
메뉴 경로

CRM›패키지›신규 패키지›상세관리

  1. 01패키지 코드, 이름, 적용 지점, 운영 기간을 입력합니다.
  2. 02비활성 상태에서 ‘쿠폰 추가’를 눌러 승인, 활성된 쿠폰과 발급 수량을 지정합니다.
  3. 03구성을 검수한 뒤 ‘활성화 (자동 발급 시작)’를 누릅니다.
Q추가할 쿠폰이 목록에 없어요.

쿠폰의 상태가 ‘활성’, 승인이 ‘승인됨’인지 확인합니다. 추가할 때는 쿠폰의 적용 지점도 함께 확인합니다.

Q운영 중인 패키지의 쿠폰 구성이나 수량을 바꾸려면?

‘다음 버전 사본 만들기’로 새 버전을 만듭니다. 쿠폰 구성과 수량, 운영 기간을 확인한 뒤 기존 버전을 비활성화하고 새 버전을 활성화합니다. 운영 기간도 그대로 복사되므로 날짜를 다시 확인하세요.

Q기존 패키지를 끄면 발급된 쿠폰도 중단되나요?

패키지를 비활성화하면 이후 자동 발급이 중단됩니다. 이미 발급된 쿠폰은 각 쿠폰의 상태와 유효기간에 따라 사용할 수 있습니다.

04

태블릿 운영법

여권 수동발급하기

여권은 고객이 QR을 등록하면 자동으로 발급됩니다. 아래는 직원이 태블릿에서 직접 발급하는 방법입니다.

따라 할 순서

  1. 회원 조회 → 기존 발급 여부 확인
  2. 대상 / 결제 / 발급일 확인
  3. 수동 발급 → 여권 현황 확인
✓ 완료 확인

선택한 고객의 여권 현황에서 수동 발급 결과와 상태를 확인합니다.

! 주의사항

고객이 QR로 이미 등록한 여권을 다시 발급하지 않도록 기존 발급 여부를 먼저 확인합니다.

조작 순서
메뉴 경로

태블릿›주렁은행›여권

  1. 01전화번호 또는 회원 QR로 고객을 조회하고, 여권 현황에서 이미 발급된 여권이 있는지 확인합니다.
  2. 02수동으로 발급할 회원 또는 가족 구성원을 선택합니다.
  3. 03결제 완료 여부와 발급일을 확인한 뒤 신규 여권을 발급합니다.
Q발급일을 이전 날짜로 선택할 수 있나요?

오늘부터 30일 전까지 선택할 수 있습니다. 결제 내역과 실제 발급일을 확인한 뒤 입력합니다.

쿠폰 사용 처리하기

따라 할 순서

  1. 쿠폰 바코드 스캔
  2. 적용 상품 / 금액 확인
  3. 사용 확인 → 처리 결과 확인
✓ 완료 확인

‘사용 처리 완료’ 안내와 ‘오늘 쿠폰 사용 목록’에서 처리 결과를 확인합니다.

! 주의사항

바코드를 스캔한 것만으로 사용 완료가 되지 않습니다. ‘사용 확인’을 누른 뒤 결과를 확인합니다.

조작 순서
메뉴 경로

태블릿›쿠폰 사용/취소

  1. 01앱 또는 지류 쿠폰의 바코드를 스캔합니다.
  2. 02소유자와 쿠폰 이름이 고객의 요청과 같은지 확인합니다.
  3. 03적용 상품과 금액을 확인한 뒤 ‘사용 확인’을 누릅니다.
Q잘못 사용 처리한 쿠폰을 되돌리려면?

‘오늘 쿠폰 사용 목록’에서 해당 건의 ‘사용취소’를 누릅니다. 처리 후 결과를 확인하세요. 유효기간이 지난 쿠폰이나 여권 취소로 회수된 쿠폰은 다시 사용할 수 없습니다.

POS 전용 쿠폰 사용 처리
메뉴 경로

고객 앱›POS 전용 쿠폰 상세›직원확인

  1. 01POS 카운터에서 고객이 제시한 쿠폰 화면을 확인합니다.
  2. 02쿠폰 상세의 ‘POS 전용’ 표시와 쿠폰 이름, 제공할 상품을 확인한 뒤 ‘직원확인’을 누릅니다.
  3. 03고객 휴대폰에 매장 직원 확인 코드를 입력하고 ‘쿠폰 사용’을 누릅니다.
  4. 04쿠폰 사용 완료 안내를 확인한 뒤 해당 상품을 제공합니다.

쿠폰을 보여주거나 확인 코드만 입력한 상태에서는 처리가 끝난 것이 아닙니다. ‘쿠폰 사용’을 누른 뒤 완료 안내를 확인합니다.

태블릿›여권 취소

  1. 01실물 여권을 반납받고 여권 QR을 촬영하거나 스캔합니다.
  2. 02소유자, 여권 정보와 함께 혜택 쿠폰의 사용, 만료 상태를 확인합니다.
  3. 03‘여권 구매 취소’를 누르고 회수 대상을 확인합니다. 필요한 경우 사유를 입력한 뒤 ‘여권 취소 실행’을 누릅니다.
Q여권을 취소하면 어떤 혜택이 회수되나요?

해당 여권의 사용 가능한 혜택 쿠폰, 여권 구매 주화, 스탬프가 회수됩니다. 사용 완료되거나 만료된 쿠폰은 회수되지 않습니다. 실제 회수 수량은 취소 결과 화면에서 확인합니다.
