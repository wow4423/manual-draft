01

여권 QR 생성하기

따라 할 순서

  1. 묶음명 / 지점 / 수량 입력
  2. 묶음과 코드 목록 확인
  3. 납품용 코드목록 다운로드
✓ 완료 확인

묶음의 지점, 수량과 미등록 재고를 확인합니다.

! 주의사항

인쇄업체에는 ‘납품용 코드목록’을 전달합니다. ‘관리용 내보내기’에는 회원 식별자가 포함되므로 전달하지 않습니다. 테스트 주소로 인쇄 발주하지 마세요.

메뉴 위치와 자세한 조작 순서

사용할 화면
CRM → 여권QR생성 → 발행/배치관리

  1. 발행 묶음 만들기에서 묶음명, 지점, 수량을 입력합니다.
  2. 발행한 묶음을 열고 코드 목록을 확인합니다.
  3. 납품용 코드목록을 다운로드합니다.
배포 수량이 발행 총량과 다를 때

발행 총량에는 이미 등록했거나 폐기한 QR도 포함됩니다. 배포할 수량은 미등록 재고를 기준으로 확인합니다.

02

쿠폰과 촬영권 준비하기

쿠폰 생성하기

따라 할 순서

  1. 상품과 적용 지점 선택
  2. 혜택과 사용 조건 입력 후 저장
  3. 매니저가 ‘활성’ 처리
✓ 완료 확인

상품, 지점, 혜택이 의도한 내용과 같고, 승인 및 활성 상태입니다.

! 주의사항

쿠폰을 만드는 것과 고객에게 발급하는 것은 별도입니다. 적용 지점을 비워두면 전 매장 쿠폰입니다.

메뉴 위치와 자세한 조작 순서

사용할 화면
CRM → 쿠폰 → 새 쿠폰

  1. 상품 검색에서 정확한 상품명, 상품 ID를 확인합니다.
  2. 상품, 적용 지점, 표시 이름, 종류와 할인 조건을 입력합니다.
  3. 사용시간, 유효기간, 한도, 할인 중복 조건을 확인하고 저장합니다.
  4. 매니저 권한 담당자가 목록의 ‘활성’을 누른 뒤, 상태 ‘활성’과 승인 ‘승인됨’을 확인합니다.
발급한 뒤 조건이 잘못된 것을 알았다면

발급 이력이 생기면 이름 외 조건을 수정할 수 없습니다. 잘못된 쿠폰은 비활성화하고 올바른 조건으로 새로 만듭니다. N+M의 증정 상품을 비워두면 구매 조건에 사용한 같은 상품이 무료 처리됩니다.

쿠폰 발급하기

따라 할 순서

  1. 쿠폰 선택 → 즉석발행
  2. 지급할 회원 선택
  3. 사유 입력 → 발행
✓ 완료 확인

‘발행 완료’ 메시지와 발행 번호를 확인합니다.

! 주의사항

같은 전화번호의 부모, 자녀를 구분합니다. 이 화면의 발급으로 알림톡이 자동 발송되지는 않습니다.

메뉴 위치와 자세한 조작 순서

사용할 화면
CRM → 쿠폰 → 해당 쿠폰의 즉석발행

  1. 쿠폰의 상태 ‘활성’과 승인 ‘승인됨’을 확인하고 ‘즉석발행’을 누릅니다.
  2. 전화번호, 닉네임, 회원번호로 검색해 지급할 회원을 선택합니다.
  3. 발행 사유를 입력하고 확인합니다.
여권 구매 고객에게 자동으로 제공하려면

한 명씩 즉석발행하는 대신 아래 여권 패키지에 쿠폰과 수량을 구성합니다. 패키지의 자동 발급 상태, 지점, 운영 기간을 확인합니다.

사진 촬영권 쿠폰 등록/사용하기

따라 할 순서

  1. 지점 선택 → 번호 파일 열기
  2. 채택 / 제외 확인 → 적재
  3. 촬영권 쿠폰 저장 → 매니저 활성
✓ 완료 확인

선택한 지점에 사용 가능한 번호가 있고, 발급된 촬영권이 번호 형식으로 표시됩니다.

! 주의사항

번호가 0개면 발급되지 않습니다. ‘발급됨’ 수량을 실제 촬영 완료 수량으로 판단하지 마세요.

메뉴 위치와 자세한 조작 순서

사용할 화면
CRM → 촬영권 번호 / 쿠폰 → 새 쿠폰

  1. 지점 선택 후 업체 파일(TXT, CSV, XLSX)을 열어 미리보기를 확인합니다.
  2. 지점명, 파일명, 채택, 제외 값을 대조한 뒤 ‘○○건 적재’를 누릅니다.
  3. 신규 적재 수와 사용 가능한 번호 수를 확인합니다.
  4. 쿠폰에서 사진관 상품, 지점 한 곳, ‘사진 촬영권 (번호 입력 방식)’을 선택하고, 저장 후 매니저가 ‘활성’ 처리합니다.
파일의 번호 수만큼 등록되지 않았다면

같은 지점에 이미 있는 번호는 제외됩니다. XLSX는 첫 번째 시트만 읽습니다. 미리보기에서 실제 번호가 제외된 경우 적재하지 말고 업체에 파일을 다시 요청합니다. 현재 CRM 촬영권 번호 화면에는 촬영 완료를 수동 반영하는 기능이 확인되지 않아, 사용 내역 대조, 반영 방법은 담당자 확인이 필요합니다.

여권 패키지 설정하기

따라 할 순서

  1. 비활성 패키지 만들기
  2. 쿠폰과 발급 수량 추가
  3. 검수 → 자동 발급 활성화
✓ 완료 확인

패키지의 지점, 기간, 쿠폰 구성이 맞고 자동 발급이 활성 상태입니다.

! 주의사항

패키지 운영 기간은 자동 발급하는 기간입니다. 이미 발급된 쿠폰의 유효기간과는 다릅니다.

메뉴 위치와 자세한 조작 순서

사용할 화면
CRM → 패키지 → 신규 패키지 → 상세관리

  1. 패키지 코드, 이름, 적용 지점, 운영 기간을 입력합니다.
  2. 비활성 상태에서 ‘쿠폰 추가’를 눌러 승인, 활성된 쿠폰과 발급 수량을 지정합니다.
  3. 구성을 검수한 뒤 ‘활성화 (자동 발급 시작)’를 누릅니다.
운영 중인 패키지의 쿠폰 구성을 바꾸려면

다음 버전 사본을 만들어 쿠폰 구성, 수량, 기간을 확인합니다. 기존 버전을 비활성화한 다음 새 버전을 활성화합니다. 두 버전을 동시에 활성화하지 않습니다. 기존 버전을 끄더라도 이미 발급된 쿠폰은 각 쿠폰의 상태와 유효기간을 따릅니다.

03

태블릿 운영법

여권 수동발급하기

여권은 고객이 QR을 등록하면 자동으로 발급됩니다. 아래는 직원이 태블릿에서 직접 발급하는 방법입니다.

따라 할 순서

  1. 회원 조회 → 기존 발급 여부 확인
  2. 대상 / 결제 / 발급일 확인
  3. 수동 발급 → 여권 현황 확인
✓ 완료 확인

선택한 고객의 여권 현황에서 수동 발급 결과와 상태를 확인합니다.

! 주의사항

고객이 QR로 이미 등록한 여권을 다시 발급하지 않도록 기존 발급 여부를 먼저 확인합니다.

메뉴 위치와 자세한 조작 순서

사용할 화면
태블릿 → 주렁은행 → 여권

  1. 전화번호 또는 회원 QR로 고객을 조회하고, 여권 현황에서 이미 발급된 여권이 있는지 확인합니다.
  2. 수동으로 발급할 회원 또는 가족 구성원을 선택합니다.
  3. 결제 완료 여부와 발급일을 확인한 뒤 신규 여권을 발급합니다.
발급일 변경 또는 가족 양도가 필요하다면

문서상 발급일은 현재 날짜 기준 한 달 전까지 선택할 수 있습니다. 가족 양도는 같은 회원에 귀속된 가족 사이에서 소유자를 변경하는 기능입니다. 대상과 발급일을 확인한 후 처리합니다.

쿠폰 사용 처리하기

화면을 보며 따라 하기조작 영상 준비 중

따라 할 순서

  1. 쿠폰 바코드 스캔
  2. 소유자 / 쿠폰 / 금액 확인
  3. 사용 처리 → 이력 확인
✓ 완료 확인

오늘 사용 이력에서 해당 쿠폰의 처리 결과를 확인합니다.

! 주의사항

스캔한 것만으로 끝나지 않습니다. 사용 처리 결과를 확인합니다.

메뉴 위치와 자세한 조작 순서

사용할 화면
태블릿 → 쿠폰/사용취소

  1. 앱 또는 지류 쿠폰의 바코드를 스캔합니다.
  2. 소유자와 쿠폰 이름이 고객의 요청과 같은지 확인합니다.
  3. 금액 계산을 확인하고 사용 처리합니다.
스캔 실패 또는 잘못 사용 처리했다면

스캐너 연결, 입력 포커스, 화면 밝기와 각도를 확인합니다. 계속 실패하면 결제와 쿠폰을 확인한 뒤 쿠폰 도구(PC)의 전화번호 검색을 사용합니다. 잘못 처리한 건은 오늘 사용 이력에서 사용 취소 후 복구 결과를 확인합니다.

부록: POS 전용 쿠폰 사용처리하기

사용할 화면
고객 앱 → POS 전용 쿠폰 상세 → 직원확인

  1. POS 카운터에서 고객이 제시한 쿠폰 화면을 확인합니다.
  2. 쿠폰 상세의 ‘POS 전용’ 표시와 쿠폰 이름, 제공할 상품을 확인한 뒤 ‘직원확인’을 누릅니다.
  3. 고객 휴대폰에 매장 직원 확인 코드를 입력하고 ‘쿠폰 사용’을 누릅니다.
  4. ‘쿠폰 사용 완료’ 화면을 확인한 뒤 해당 상품을 제공합니다.

쿠폰을 보여준 것만으로는 사용 완료가 아닙니다. 직원 코드 인증 후 완료 화면까지 확인합니다.

여권 취소하기

화면을 보며 따라 하기조작 영상 준비 중

따라 할 순서

  1. 실물 반납 → 여권 QR 스캔
  2. 소유자와 혜택 쿠폰 상태 확인
  3. 사유 입력 → 취소와 회수 확인
✓ 완료 확인

취소 결과와 회수된 미사용 혜택 쿠폰 수를 확인하고 고객에게 안내합니다.

! 주의사항

이미 사용한 쿠폰과 미사용 쿠폰을 구분합니다. 화면의 취소 결과를 확인한 뒤 안내합니다.

메뉴 위치와 자세한 조작 순서

사용할 화면
태블릿 → 여권 취소

  1. 실물 여권을 반납받고 여권 QR을 촬영하거나 스캔합니다.
  2. 소유자, 여권 정보와 함께 혜택 쿠폰의 사용, 만료 상태를 확인합니다.
  3. 여권 구매 취소를 누르고 사유를 입력해 진행합니다.
회수되는 쿠폰은 무엇인가요?

문서에서 안내하는 회수 대상은 여권 구매 시 제공된 미사용 혜택 쿠폰입니다. 사용, 만료 상태를 먼저 확인합니다. 결제 환불의 상세 기준과 절차는 이 문서에 명시되어 있지 않습니다.
